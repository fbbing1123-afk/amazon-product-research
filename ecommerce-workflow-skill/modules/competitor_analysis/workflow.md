# 当前竞品分析流程

执行本文件及Skill当前规则，不需要选择版本。空模板输入为用户当前模板、商品源和竞品分析A1标题中的本批ASIN，按列顺序生成详情链接；已有报告需核对标题ASIN和详情链接一致。

1. **确认范围**：完整竞品或只做基础字段。跳过评价时不下载评论、不填优缺点和总结；只给单独商品时另建批，不混入工作簿其它商品的分析。
2. **基础与预取**：按[基础字段](../../docs/competitor_basic_facts.md)、[预取调度](../../docs/review_prefetch.md)操作。数据源逐字段优先，缺数据或缺ASIN到对应详情页补；缺卖点读取About this item。需要评价时先打开全部目标页并启动插件导出，等待时做其它截图/填数。
3. **高清主图**：按[主图规则](../../docs/product_images.md)下载网页原文件，核验当前选中ASIN及真实尺寸，原尺寸浮动；市场调研A1放第一款竞品同图。
4. **中文卖点与对比**：主智能体根据本批证据整理，最多5维度；Alexa推荐问题只做选维度参考。未知写“页面未明确说明是否……”，网页读取失败另注明。规格数值局部红色加粗，保留格式并动态增行。
5. **准备评价**：从本批插件下载原Excel准备编号评论，VP/Vine、赞同数降序，好评4–5星前30、差评1–3星前100，按[评价分析](../../docs/sellersprite_review_analysis.md)准备及校验。
6. **实际分析**：主智能体归纳好评；本批一个全新上下文子智能体只读按ASIN分组的编号评论，每条差评原因15字内，列全所有提及序号。不能传旧角色或旧痛点库；主智能体回查证据，脚本计算百分比。没有子智能体能力需明确该阶段未完成。
7. **写表与合源**：基础用 `populate_basics.py`，批量评价用 `fill_review_batch.py`，从同一批最新检查点顺序写。每商品优点/缺点各一格，缺点百分比降序；总结按“总结：…\n改进方式：\n1. …”并使用真实换行。全部原评论自动合并回唯一“评价数据源”。
8. **验收**：按[当前交付规范](../../docs/delivery_checks.md)核对来源、样式、动态布局、高清图片、空差评状态、比例和全部评论。只补缺失，不重复抓取。已有成品的局部修复使用对应ZIP入口。

不调用旧 `run.py`、`prepare_review_analysis.py`、`backfill_review_analysis.py`、差评透视或切片器后处理，也不读取旧语义缓存。分析指令来自本批 `sellersprite_review_analysis.py prepare` 产生的提示材料；Python准备JSON不等于已完成子智能体分析。
