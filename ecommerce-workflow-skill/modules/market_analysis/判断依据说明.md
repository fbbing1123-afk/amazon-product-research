# 判断依据说明

本文档记录当前市场分析报表中各模块写结论、识别异常样本、划分区间时使用的判断依据。

> 说明：本文档是给人看的判断逻辑说明，不是脚本运行时读取的配置文件。后续如果要调整判断逻辑，建议先修改本文档，再同步修改 `excel_market_report.py`。

## 1. 总览结论判断依据

总览结论会写入：

- `报表总览` sheet 的结论摘要区域；
- `市场分析` 模板页的 `A8` 单元格。

### 1.1 基础指标

| 指标 | 说明 |
|---|---|
| 样本数 | 有有效 `月销量` 的商品链接数量 |
| 总月销量 | 所有有效样本的 `月销量` 合计 |
| 总月销售额 | 所有有效样本的 `月销售额($)` / `月销售额(€)` 等同义字段合计，货币符号按数据源表头自动识别 |
| 平均月销量 | 有效样本 `月销量` 的平均值 |
| 中位月销量 | 有效样本 `月销量` 的中位数 |
| 中位价格 | 有效价格样本的中位数 |
| Top10 销量占比 | 销量排名前 10 的样本月销量合计 / 总月销量 |

### 1.2 头部集中度

| 判断结果 | 判断条件 |
|---|---|
| 高 | Top10 销量占比 >= 55% |
| 中 | Top10 销量占比 >= 35%，且 < 55% |
| 低 | Top10 销量占比 < 35% |

### 1.3 最终建议

| 输出建议 | 判断条件 |
|---|---|
| 谨慎进入 | 头部集中度为“高” |
| 可重点评估 | 头部集中度为“中”或“低” |
| 样本偏少，建议补充数据后再决策 | 样本数 < 20。该条件优先级最高，会覆盖上面两种建议 |

### 1.4 总览结论文案逻辑

总览结论主要表达以下含义：

1. 样本数、总月销量、总月销售额用于判断该方向是否存在真实需求。
2. 平均月销量和中位月销量用于观察市场是否被少数头部链接拉动。
3. Top10 销量占比用于判断头部集中度。
4. 中位价格用于辅助判断市场主流价格带。
5. 最终建议会结合头部集中度和样本数输出。

## 2. 销量分析小结判断依据

销量分析小结写入 `市场分析` 模板页的 `A20` 单元格。

| 内容 | 判断依据 |
|---|---|
| Top10 销量占比 | 销量排名前 10 的样本月销量合计 / 总月销量 |
| 头部集中度 | 使用“总览结论”中的头部集中度判断规则 |
| 平均月销量 | 有效样本 `月销量` 的平均值 |
| 中位月销量 | 有效样本 `月销量` 的中位数 |
| 建议关注方向 | 默认建议重点看中腰部链接是否具备可追赶空间 |

当前小结不会根据中腰部数据额外输出不同建议，只会固定提醒关注中腰部链接的追赶空间。

## 3. 评论/评分数分析小结判断依据

评论/评分数分析小结写入 `市场分析` 模板页的 `A34` 单元格。

| 内容 | 判断依据 |
|---|---|
| 低评分数样本范围 | 评分数 <= 30，即 `≤30评` 区间 |
| 低评分数样本平均月销量 | `≤30评` 区间内样本月销量平均值 |
| 低评分数样本中位月销量 | `≤30评` 区间内样本月销量中位数 |
| 解读逻辑 | 如果均值明显高于中位数，说明低评起量更多来自少数异常样本，不能简单判断为低评好打 |

当前脚本只输出上述解释，不会自动计算“明显高于”的额外阈值。

## 4. 价格段分析小结判断依据

价格段分析小结写在动态价格段表格下方；如果价格段数量变化，写入行会随表格自动顺延。

| 内容 | 判断依据 |
|---|---|
| 销量贡献最高的价格段 | 在所有已知价格段中，选择总月销量最高的价格段 |
| 总月销量 | 该价格段内所有样本的月销量合计 |
| 新品切入提示 | 固定提醒需要结合该价格段的销量、评分门槛和产品差异化承接判断 |

说明：`未知价格` 不参与“销量贡献最高价格段”的选择。

## 5. 异常样本识别依据

异常样本会写入 `异常样本` sheet。

异常样本用于复核，不等于直接判定机会或风险。

| 异常原因 | 判断条件 | 复核方向 |
|---|---|---|
| 低评分数高销量 | 评分数 <= 30，且月销量 >= max(80, 低评分数样本月销量中位数) | 检查评价沉淀是否真实、是否存在站外或品牌流量 |
| 月销量/评分数比值偏高 | 月销量 / 评分数 >= 8，且月销量 >= 50；如果评分数为空或为 0，则用月销量作为该比值 | 检查是否存在短期放量、广告、站外或统计异常 |
| 上架时间短但销量较高 | 上架天数 <= 180，且月销量 >= 80 | 检查是否是老链接换壳、变体合并、广告或站外带量 |
| 广告位高销量需复核自然承接 | `搜索排名` 字段包含“广告位”，且月销量 >= 80 | 检查自然位承接能力，避免只看到广告带来的销量 |

当前异常样本统一复核建议为：

> 检查广告、站外、品牌流量、老链接换壳、评价沉淀是否匹配。

## 6. 价格段分组依据

脚本会从数据源表头自动识别货币符号，例如 `价格($)`、`价格(€)`、`月销售额($)`、`月销售额(€)`。价格段不再使用固定的 `0-20`、`20-40`、`100+` 区间，而是根据有效价格的实际分布动态生成；德国站、英国站等站点只替换输出货币符号，不改变分段算法。

| 价格分布情况 | 分组方式 |
|---|---|
| 价格为空或无法识别 | `未知价格` |
| 相邻价格存在明显断层 | 在断层处分段，段数由实际断层数量决定；不因某段样本少而合并 |
| 价格连续且没有明显断层 | 使用四分位距计算自适应价格步长，按价格密度展示连续区间 |
| 价格精确到几分钱导致标签过碎 | 仅对展示边界做货币单位取整，原始价格仍按未取整数值归类 |

断层判断同时参考相邻价格差距和相对差距：候选断层通常需要达到常见相邻差距的约 3 倍，并且相对前一个价格至少约 10%。这两个值用于识别市场自然空档，不是固定价格段。

每个价格段保留真实样本数、总月销量、平均月销量、中位月销量和中位价格。市场分析页与可选的 `切片联动` 页共用同一组动态标签，避免报表和切片器不一致。

## 7. 评分数分组依据

| 评分数字段情况 | 分组 |
|---|---|
| 评分数为空或无法识别 | 未知评分数 |
| 评分数 <= 30 | `≤30评` |
| 30 < 评分数 <= 50 | `31-50评` |
| 50 < 评分数 <= 100 | `51-100评` |
| 100 < 评分数 <= 300 | `101-300评` |
| 300 < 评分数 <= 1000 | `301-1000评` |
| 评分数 > 1000 | `1000评+` |

评分数有效但月销量为空的产品，仍必须进入对应评分数区间；其月销量按 0 计入该组汇总，不能因为缺少月销量而从评分数分析中消失。评分数分析图同时标注每组样本数，避免“总月销量为 0”被误判为该区间没有产品。

## 8. 销量分层依据

| 分层 | 判断依据 |
|---|---|
| Top 10 | 按月销量从高到低排序后的前 10 个样本 |
| 第11-20名 | 按月销量从高到低排序后的第 11 到第 20 个样本 |
| 第21-50名 | 按月销量从高到低排序后的第 21 到第 50 个样本 |
| 第51名以后 | 按月销量从高到低排序后的第 51 名及以后样本 |

## 8.1 数据源辅助列与切片器

数据源切片器是待选功能，默认关闭；普通流程保持旧版输出，不增加联动页、辅助列或切片器。只有显式传入 `--market-analysis-source-slicers` 时，脚本才会新增独立的 `切片联动` sheet。该页顶部放置 3 个切片器，第 12 行开始复制完整数据源表格；原数据源 sheet 保持不变。复制表格末尾的 `销量分层`、`评分数区间`、`价格段` 3 个辅助列会隐藏，并直接复用本文件第 6、7、8 节的计算结果，因此切片器中的样本数量应与市场分析 sheet 的分层统计一致。

- 3 个切片器可以组合筛选，组合条件按交集处理。
- 没有有效月销量、未进入市场分析的源数据行，3 个辅助列统一标记为 `未纳入市场分析`。
- 切片器筛选 `切片联动` 页的数据副本，产品图片转换成 WPS `DISPIMG` 单元格内图片，并随对应行一起隐藏或显示。
- 重跑市场分析时更新现有辅助列、表格和切片器，不重复新增。
- 切片器由 `add_source_slicers.ps1` 在最终 `openpyxl` 保存后通过 Excel/WPS COM 创建。

## 9. 模板页写入位置

如果 Excel 中已经有 `市场分析` 模板页，脚本只往预留位置写入数据、结论和图表，不主动重设模板的行高、列宽、合并单元格、字体、颜色、边框和版式。

复用旧案例模板时，脚本先按本次产品名统一 `市场调研`、`市场分析`、`竞品分析` 和 `数据源` 的 Sheet 前缀。3 张市场分析图生成后立即转为静态 PNG，后续评论、竞品和切片器步骤不再依赖原生图表的 Sheet 引用缓存。

### 9.1 结论写入位置

| 位置 | 内容 |
|---|---|
| `A8` | 总览结论 |
| `A20` | 销量分析小结 |
| `A34` | 评论/评分数分析小结 |
| 动态价格段表格下方 | 价格段分析小结；价格段行数变化时自动顺延 |

### 9.2 标题保留位置

| 位置 | 内容 |
|---|---|
| `A19` | 保留销量分析标题 |
| `A33` | 保留评论分析标题 |
| `A46` | 保留价格分析标题 |

### 9.3 图表锚点

| 图表 | 锚点 |
|---|---|
| 销量分层图 | `A12` |
| 评论数区间图 | `A24` |
| 价格段图 | `A38` |

## 10. 修改流程建议

后续如果要调整判断逻辑，建议按这个顺序处理：

1. 先修改本文档中的判断依据。
2. 再根据本文档同步修改 `excel_market_report.py`。
3. 运行测试，确认报表生成逻辑没有被改坏。
4. 如果输出文案或模板位置发生变化，同步检查 README 中的入口说明是否仍然准确。
