# 商品页高清主图与原尺寸浮动放置

2026-11-25用户确认：产品图优先从对应Amazon详情页取得高清主图，按原始像素尺寸浮动放入Excel，之后由用户手动调整大小并嵌入。图片不截图、不裁切、不重采样，不为容纳图片调整行高、列宽或其它内容。原尺寸图片暂时覆盖相邻区域属于用户选择的放置方式。

## 采集和定点替换

在项目专用浏览器已经打开、美国站及配送邮编已经确认后，进入技能目录执行：

```powershell
python modules/competitor_analysis/collect_product_images.py ASIN1 ASIN2 --output-dir "本地图片目录"
python modules/competitor_analysis/refresh_product_images.py --workbook "当前报告.xlsx" --images "采集目录/images.json" --output "高清主图版.xlsx"
```

采集入口也接受美国站详情页链接，默认连接项目浏览器 `http://127.0.0.1:9223`。目标ASIN不要求出现在商品数据源里。每个商品采集完成即保存清单，失败保留页面，成功只关闭本入口新建的页面。出现真人验证时由用户处理后定点续跑，不代勾。

只读取页面主图节点实际提供的原图/动态图片地址，优先原图，再按动态尺寸选择；不猜测高清URL、不拼接图片后缀。页面网址、选中ASIN和目标必须一致。Amazon重复的ASIN节点仅在值全部相同时接受，出现冲突则拒绝。图片清单记录来源网址、时间、邮编文案、像素和SHA256，写入前再次核验归属、文件指纹及格式。长边不足1000像素时如实标记，不能把小图放大后称为高清。

定点替换只依赖竞品ASIN、详情链接和“产品图”标签，支持没有商品数据源页、没有旧主图的工作簿。它直接更新XLSX绘图部件并新增媒体文件，原源表及其它原生部件保留，输出必须是独立新文件。默认要求覆盖全部竞品；只补部分时显式使用 `--allow-partial`。默认 `--display-mode original`，只有明确选择适配显示框时才使用 `fit`，两种模式都保留原图文件像素。

## 基础填表与预取调度

- `populate_basics.py --images images.json` 优先使用核验后的网页主图，其次兼容原数据源图片，最后沿用旧商品卡兜底。默认 `--image-display original`。该入口适用于基础浮动图阶段，不能用于重存含切片器/WPS原生嵌入对象的完整报告；已有报告只换主图用上述ZIP入口。
- ASIN不在商品源时，基础填表可使用网页证据中的评分和评论数建立内存记录，不向原数据源造行。评分/评论数未取全会报错，不能用0代替。月销量、价格、上架时间仍走既有逐字段网页兜底；卖点和对比仍需本批原文整理。
- `run_review_prefetch.py` 复用正在导出的商品页采集主图，图片与基础字段分别记录成功/失败。依次写整体指标、基础数值、`01-product-images.xlsx`，再合并类目截图；后续从最新检查点继续。默认 `--product-image-display original`，缺图不能标记整个预取阶段完成。后续基础填表须传递该批 `main_image` 证据，不能把已取得的高清图换回数据源小图。
