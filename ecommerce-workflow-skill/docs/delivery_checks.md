# 当前新版交付验收

仅检查用户本次授权的范围。完整市场调研需要关键词、类目和数据概览三个小节；只生成网页市场报告时不要求填Excel。缺项先定点补齐，受阻就说明真实完成范围，不能用脚本成功退出代替交付。

## 工作簿和布局

- 原始文件指纹不变，结果另存。ZIP有效、无损坏媒体引用，无 `#REF!`、`#DIV/0!`、`#VALUE!`、`#N/A`、`#NAME?`、`#NUM!` 等公式错误。
- 保留模板字体、主题填色、细边框、对齐、行列尺寸、合并及富文本。加载需使用 `rich_text=True`。含WPS原生图片的成品定点修改使用ZIP方式；不能用整体重存破坏已有部件。
- 关键词/类目/对比/评价增行后，下方单元格、合并、格式和图片锚点全部随动，按当前标签重新定位；不能沿用历史行号。
- 竞品按详情链接从左到右对应列。保持原C:G产品列宽；超过5款时复制G列格式，标题及总结正文合并区扩至最后产品列。原有空栏保留，不填占位商品。
- 每商品优点、缺点各一个单元格，长内容通过模板续行纵向合并，格内换行，后方总结下移。正文只写合并区域左上格。
- 全部填数完成后执行[最终全图嵌入](final_image_embedding.md)。核对嵌入数量等于原浮动图数量、浮动图为0，原媒体、行高、列宽、合并、样式及非图片内容不变；不得为嵌入图片调整单元格大小。嵌入后不再整体重存成品。

## 市场调研

- 逐行核对关键词、Amazon链接、趋势图、旺季、站内结果、淡季/月搜索量、旺季/月搜索量和最新周竞价，记录实际周日期；按旺季月搜索量降序且链接、图与格式同移。
- 每个类目中文和末级BSR超链接有效，链接落在本行末级名称格；月销量与数量占比真实换行显示且底色保留。
- 类目图从卖家精灵取图，统一范围，面板出现后满20秒且无加载动画，像素有效；中间阶段原尺寸浮动，最终统一嵌入，不改行高列宽。浏览器缩放须换算，最小化时截图前恢复。
- 12项整体指标完整，数值整数显示、Top5/10/20占比整数百分比，原值不舍弃精度；右侧结论区域不写。
- 品牌与上架时间六图、Review/Rating/价格三图齐全且次序和标签正确。六张本地图按对应图框适配；三张报告截图按原像素尺寸浮动定位到各自图框左上角，不缩放、不居中适配，允许暂时遮挡邻格供用户手动调整。报告URL及真实样本数可追溯，不能把源数覆盖报告样本。
- 不新增独立市场分析页，不要求旧页的三张冻结图。

## 竞品与评价

- 月销量、价格、上架时间、评分/评论数按ASIN及字段核对来源；源缺失网页补取。中文卖点由本批原文生成。
- 主图优先详情页高清原文件，核验选中ASIN、URL和真实尺寸，原像素浮动。市场调研A1图片与第一款竞品主图字节一致，无重复锚点；遮挡相邻格在原尺寸模式允许。
- 最多5项对比，带单位可比较数值局部红色加粗；未说明不写成不支持，采集失败与未说明区分。
- 本批评论归属、原文件指纹、选样和结果证据一致。VP/Vine、好评前30/差评前100规则正确，实际已读全部入选差评。一个原因同一评论只计一次，比例分母是该商品本批入选差评数。
- 缺点在一个格内按百分比降序；无入选差评 `/`，有入选差评但无具体原因 `无具体差评原因`。优缺点及总结不混入其它产品旧结论。
- 总结格式为“总结：实际精简总结”，下一行“改进方式：”，随后编号建议，不加依据行。
- 唯一“评价数据源”完整合并全部下载评论，最左列区分目标ASIN，原ASIN及原字段保持。三列分析按源行对齐，未入选留空，源表无百分比、入选列或分析编号；总行数等于各原文件合计。
- 用户跳过评价时，不下载评论，评价与总结区域不写内容。无法下载、导出为空或子智能体未运行不能冒充无差评。

## 实际验收方式

按适用范围运行 `modules/shared/quality_gates.py`，先核验浮动检查点，再核验最终嵌入版；图片证据兼容浮动图及WPS单元格图，模式1显示大小按实际目标单元格估算，仍检查原图清晰度。原模板通过 `--template` 传入；实际完成评价后才允许 `--allow-evaluation`。当前 `--step final` 核验合并布局，不再强制要求旧独立市场分析页；类目缺图仍会失败。参数先查 `--help`，旧 `--step market_analysis` 只供历史独立页使用，不用于当前流程。

同时读取图片真实像素，核对原尺寸主图、类目图及三张报告截图，核对六张本地图显示框及锚点无重复；渲染修改区域检查中文、富文本、图片及合并布局。结构门禁不能代替内容核验。凡最终文件再次保存，重新检查最终路径。没有Excel/WPS桌面验收时如实说明，不宣称做过。
