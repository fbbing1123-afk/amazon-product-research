# 竞品基础字段：数据源优先与网页补取

入口：`modules/competitor_analysis/collect_basic_facts.py`。

本入口负责批量取数并输出 JSON，支持 ASIN 或美国站商品链接。不会修改原 Excel，不执行图片、评论或其它竞品分析阶段；尚未接到 `populate_basics.py` 的自动填表流程。

## 字段口径

| 结果字段 | Excel 数据源列 | 缺失时读取的插件标签 |
| --- | --- | --- |
| `monthly_sales` | 月销量 | 近30天销量(父体) |
| `price` | 价格($) | 价格 |
| `listed_at` | 上架时间 | 上架时间 |

网页补取沿用用户确认的卖家精灵插件口径。插件销量属于近30天估算指标，不改用子体 `600+` 等购买量区间；价格不使用 Prime 价格、均价或划线价。日期输出为 `YYYY-MM-DD`。当前入口仅支持美国站，币种为 USD，避免跨站价格混入美元列。

## 使用方法

先打开项目专用浏览器，保持卖家精灵插件启用且已登录。在 `ecommerce-workflow-skill` 目录运行：

```powershell
python modules/competitor_analysis/collect_basic_facts.py B000TEST01 B000TEST02 --workbook "输入报告.xlsx" --output "outputs/竞品基础字段.json"
```

示例 ASIN 为占位符，实际执行时换成用户给出的 ASIN 或商品链接。

- 可一次传入多个商品，重复 ASIN 自动去重。
- 默认连接 `http://127.0.0.1:9223`；用 `--cdp` 指定项目浏览器地址。不会自动新建浏览器配置或改登录信息。
- 有多个数据源页时，用 `--source-sheet "具体页名"` 指定。
- `--source-only` 只检查 Excel，不连接浏览器。
- `--timeout` 指定等待插件数据的秒数，默认25秒，可设1～60秒。

## 定位与保底规则

1. 在数据源中精确匹配 ASIN，再按字段读取；有效的 0 销量保留。
2. 三项都有有效数据时不打开网页。仅部分字段缺失时，网页只补缺失字段，不能覆盖已有值。
3. 打开规范商品地址 `/dp/<ASIN>`，限定读取 `#seller-sprite-extension-quick-view-listing` 区域；同时核对页面 URL 和插件中显示的 ASIN，防止推荐商品或变体跳转造成串值。
4. 插件所需字段齐全且连续两次读取一致后返回；找不到、未登录、验证码、跳转商品或超时均记录原因。不会自动处理验证码。
5. 同 ASIN 的多条数据源记录若存在字段冲突，保留冲突状态，不能让网页悄悄覆盖。
6. 每完成一个商品就写一次 JSON 检查点。单个商品失败时继续处理后续商品，返回缺失字段及错误原因；全部完整退出码为0，有不完整项为2。
7. 结果按字段记录数值、来源、原标签；Excel 来源附页名和行号，网页来源附 URL 与 UTC 采集时间。
8. 关闭时只关闭本次脚本新开的页并停止连接，不关闭用户项目浏览器及原有标签页。
