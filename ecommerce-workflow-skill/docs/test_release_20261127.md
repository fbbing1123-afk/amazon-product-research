## 建议同事这样测试

1. 新目录完整解压，先读“开始使用.txt”和[使用指南](使用指南.md)。让AI核验已有Python/Node环境，可用即复用，缺依赖才安装在项目内；不要删除浏览器配置、缓存或重装全局依赖。
2. 用项目浏览器安装并登录卖家精灵插件，核验网页登录、Amazon站点及邮编。提供自己的已填Excel并说明运行范围，先用少量竞品和类目测试。
3. 运行中观察已知确认页是否被唤醒、处理及回到正确目标；其它验证如实处理。评论只应启动一次导出，失败后从已有检查点定点恢复。
4. 检查类目最多10个、市场七处都有实际分析及局部标红，并能追溯本批证据；检查--、暂无数据和评论缺译是否被如实记录；对照商品ASIN、原评论、图表、指标及总结，不能只看脚本是否退出。
5. 用WPS打开最终单元格图片版，对照浮动检查点：全部图片嵌入、无浮动图，行高、列宽及合并区域不变，原文件未覆盖。不要在最终嵌入后让openpyxl整体重存。
6. 反馈包版本/源提交、站点/邮编、WPS版本、输入商品/竞品/类目数量、失败阶段、报错或截图、本批记录及检查点路径。说明哪些成功、哪些缺失；不要发送密码、Cookie或整个浏览器配置。
