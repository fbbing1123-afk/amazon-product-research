# 亚马逊选品自动化 Skill 使用说明

这份工具不需要同事研究代码。解压后，在 Codex 中使用 `ecommerce-workflow-skill` 文件夹开启对话，再把下面对应的指令发给 AI 即可。

## 第一步 用技能文件夹开启对话

1. 解压收到的 ZIP。
2. 找到解压后的 `ecommerce-workflow-skill` 文件夹。
3. 在 Codex 中打开或选择这个文件夹作为当前项目，再新建对话。
4. 第一次对话先发送：

```text
请先阅读当前文件夹里的 SKILL.md 和 docs/使用指南.md，确认你已经理解这个亚马逊选品自动化工作流。先检查运行环境，不要开始处理 Excel。
```

不要只把 `SKILL.md` 单独拿出来使用。`scripts`、`modules` 和 `resources` 都是程序运行所需文件。

## 第二步 第一次使用时让 AI 准备环境

在同一个对话中发送：

```text
这是这台电脑第一次使用该工具。请运行首次环境准备和安装后自检，持续检查到环境可用。缺少 Python、Node.js 或浏览器时请明确告诉我，不要跳过错误，也不要开始运行 Excel 工作流。
```

环境准备完成后，再发送：

```text
请打开美国站项目专用浏览器，我需要安装插件并登录。先不要运行 Excel 工作流。
```

如果要做其它站点，把“美国站”改成德国站、英国站、加拿大站或法国站。

浏览器打开后，同事自己完成以下操作：

- 安装 softtime 或 sorftime 浏览器插件。
- 登录卖家精灵。
- 登录目标 Amazon 站点。
- 确认 Amazon 左上角配送邮编正确。

不要把账号密码、Cookie 或验证码发送给 AI。

## 第三步 把 Excel 交给 AI

把需要处理的 Excel 添加到当前对话，然后根据任务复制下面的指令。

### 运行完整流程

```text
请阅读当前文件夹的 SKILL.md，并使用这里的程序处理我提供的 Excel。运行美国站完整流程，邮编 10001。先检查输入文件、环境、登录态和已有结果，然后持续监控，直到关键词调研、类目调研、市场分析、评论调研、竞品分析、差评透视、切片器和最终验收全部完成。已有结果不要重复运行。
```

### 只运行部分功能

```text
请阅读当前文件夹的 SKILL.md，并使用这里的程序处理我提供的 Excel。只完成英国站的类目调研和市场分析，邮编 B100AB。不要运行评论调研和竞品分析。
```

### 从中断处继续

```text
请阅读当前文件夹的 SKILL.md，检查我提供的工作簿和最近缓存，从第一个未完成步骤继续。已完成的关键词、截图、图表和评论不要重跑，并持续监控到本次任务完成。
```

### 只补缺失内容

```text
请阅读当前文件夹的 SKILL.md，检查这份报告，只补缺少的翻译、截图、字段、图表或商品卡。先列出缺失项，再逐项补齐，不要重跑整个流程。
```

## 每次对话要说清楚什么

告诉 AI 以下四项即可：

1. 要处理哪个 Excel。
2. 目标站点，例如美国站或德国站。
3. 邮编，例如美国站 `10001`、德国站 `10115`、英国站 `B100AB`。
4. 要运行完整流程、部分功能，还是从中断处继续。

## 怎么判断完整流程已经完成

完整流程必须完成关键词、类目、市场分析、评论、竞品分析、差评透视、3 个橙色切片器和最终验收。AI 只完成前几个脚本步骤时，还不能算完整流程结束。

最终 Excel 通常会放在桌面的 `亚马逊产品调研流程输出表` 文件夹。中间缓存位于桌面的 `亚马逊产品调研流程缓存`，用于断点续跑，不要在任务运行时删除。

## 遇到错误时怎么说

不要让 AI 从头重跑。把错误保留在当前对话中，然后发送：

```text
请读取当前工作流监控日志，说明具体卡在哪一步，并从最近成功检查点定点续跑。不要重跑已经成功的步骤。
```
