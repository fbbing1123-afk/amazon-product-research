# 模板填写说明

随包提供 `assets/产品调研模板.xlsx`，原样复制自用户确认的“副本-开发.xlsx”。文件含当前市场调研、竞品分析和空数据源表头，无商品数据、图片或外部工作簿链接。每个产品先复制一份再填，不覆盖包内母版。

## 需要填写的三处

| 位置 | 填什么 | 用来做什么 |
| --- | --- | --- |
| `产品名-市场调研` 的A3合并格 | 保留“●竞品关键词反查”，把后面的示例ASIN替换为目标ASIN，多个用 `/` 分隔 | 这些商品的关键词反查及后续关键词趋势分析 |
| `产品名-竞品分析` 的A1合并格 | 保留“4. 竞品分析-US：”，替换后面的示例ASIN，多个用 `/` 分隔 | 从左到右确定要对比和分析评价的商品 |
| `产品名-数据源` | 保留第1行字段名，从第2行填自己的卖家精灵商品数据 | 整体销售指标、类目和品牌分析、集合链接及竞品字段来源 |

示例写法：`●竞品关键词反查 B0GL1TCL7Q/B0D2KRPBCW`；竞品标题为 `4. 竞品分析-US：B0GL1TCL7Q/B0H71PH7MN`。使用时将这些示例值换成自己的真实目标。

两组ASIN互相独立，可以不同；数据源ASIN也不限于这两组。竞品不在数据源时可到网页补基础数据，不能因此把整行商品源编造出来。ASIN是10位字母数字编号，使用普通文本和英文 `/`，不在ASIN中插空格。

首次空模板无需再手填“详情页链接”行，程序会按竞品标题ASIN写入。已有报告继续时，标题ASIN与已填详情链接必须一致；若手动换了商品，要让AI重新确认本批目标，不能混用上次的列、评论和结论。

## 产品名称和站点

当前页名中的 `flower+press+kit` 为示例产品名。可按需改成自己的产品名；三个页名前缀不必一致，首尾空格也会自动兼容。保留市场调研、竞品分析、数据源模块后缀和内部表头即可。程序优先从商品源前缀确定输出产品名，不要求用户先统一页名。

当前模板价格单位为美元。站点先用用户指定值，未指定时按商品源或竞品链接识别，均无信息才用美国站和10001。其它已配置站点直接取对应默认邮编；AI按实际站点处理币种与可用模块，模板示例US标题不作为重复询问的理由。

## 其余格子

关键词结果、趋势图、整体指标、类目表现、主图、详情链接、评分、卖点、对比维度、优缺点和总结由流程填入。预留行或产品列不足时按当前布局规则动态扩展，不需要同事先手动改行高列宽。

模板目前放了6个关键词反查示例ASIN、6个竞品示例ASIN，但只有5个默认竞品展示栏位、3个对比维度预留行；这是可扩展模板，程序按实际商品数和最多5项维度扩容，保持下方格式和图片随动。

完成填写后，将工作副本交给AI并要求运行即可；有特殊站点、邮编或仅运行部分模块的要求再单独说明。AI自动读取输入并继续，不要求再次确认开始。评分、评分数、销量等为空是正常情况，无需用户逐项确认或补齐，网页后备机制仍按当前规则执行。两组ASIN均已通过当前解析函数核验；完全没有商品行的母版需先填入商品源。
