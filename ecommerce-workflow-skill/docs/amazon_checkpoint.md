# Amazon确认页接入

2026-11-27按用户提供的监听脚本接入业务流程，并使用用户Excel真实试跑。本轮代码纳入20261127-test1本地Git测试版；不启动独立监听进程，不新建浏览器连接。

## 当前行为

`modules/shared/amazon_checkpoint.py`提供同步和异步处理入口；`amazon_access.py`提供带目标核验的访问及导航入口。仅在支持的Amazon域名、`/checkpoint/continue`路径，同时出现`#continueCheck`及英文`Continue shopping`按钮时勾选并提交。默认每次最多15秒、两次提交；同一失败文档不反复尝试，刷新或导航后才允许再处理。

离开确认页且连续两次识别为普通页面后返回`cleared`，随后业务核验原目标地址。商品必须对应原ASIN，搜索词/集合参数必须一致，类目允许同站同节点的规范地址。其它商品、首页或其它站点不算数据可读。若本次确认已通过，却落到其它普通Amazon页面，且业务明确传入了原目标，则在当前标签重新进入原目标一次，再核验目标、邮编及插件。

重进导航最多45秒；若再次遇到已知确认页，仍按每页15秒、两次提交处理，但不再进行第二次目标重进。重进后仍走错页、网络错误、登录或其它验证均保留页面及进度并暂停。普通页面的目标不匹配不会触发此恢复，无原目标时不猜链接，也不跳转到外站或登录/验证地址。返回结果保留`cleared`并标记`target_reentered`，使类目继续执行插件重新注入后的固定等待；日志记录`checkpoint_target_reentry`。

登录、其它验证码、未知确认页面及处理超时沿用受阻结果，保留页面、已下载文件和检查点。处理结果包含状态、尝试次数和耗时；日志网址去除查询参数和片段。不能仅凭脚本退出码或`cleared`认定业务完成。

## 业务接入

- 关键词：在导航和访问检查中调用，处理失败保留页面并抛出原有可续跑异常；成功后核验搜索词、配送邮编再取数。
- 评论预取：复用原UI操作锁、单一连接及下载路由，默认仍最多2商品。确认恢复期间不补开新商品/类目；已有下载继续接收事件。导出中途跳转后重新核验ASIN、邮编与插件，只等待原导出，不再点击下载。下载完成后再校验页面及文件。
- 类目：导航、加载及截图前检查访问状态；恢复后重新核验邮编及插件排版，保留出现面板后等待满20秒的规则。
- 竞品基础、独立主图及单商品评论下载：按同一规则处理，受阻时保留页面并停止下一商品。单商品下载不再进入旧的5分钟等待点击循环；旧兼容函数仅保留供历史代码使用。

业务直接使用已有`page`，浏览器端口继续由项目启动器及`browser_runtime`读取，不硬编码9223。独立监听不与业务同时负责点击，避免抢占页面和重复提交。

业务日志的`seconds`保持批次时钟，确认页处理耗时通过`handling_seconds`传入，避免覆盖批次时刻。类目成功只关闭本轮新建的标签页，用户原有页及失败页保留。试跑发现的平台明确缺失指标按[类目规则](market_research_category_section_rules.md)原样记录，不冒充数值或加载成功。

确认控件已出现时，先将目标标签置前；窗口处于最小化时恢复正常窗口，再通过标准勾选及点击操作提交。后台页面可能无法及时提供Playwright位置稳定检查需要的动画帧，不能把“元素可见”当作“点击已完成”。日志记录`checkpoint_checked`，失败信息区分`activate`、`check`、`submit`及等待目标步骤，不输出带令牌的网址。

## 验证及限制

同步/异步、同页互斥、失败缓存、目标匹配、导航超时恢复和已有并发回归使用可控测试。额外使用隔离无头Chrome、全部网络请求本地拦截的页面，检查真实勾选跳转及导出中途恢复；下载完成事件和文件落盘在该模拟场景中受控替代。

真实美国站/10001试跑中，8个关键词及7款竞品基础和高清主图采集完成。关键词、商品和类目页面实际出现确认页，已有约3.4～4.8秒、一次提交后恢复并完成业务的记录。评论翻译导出首次停滞，用户开启代理后定点重试成功，7款合计56条；其中一款8条没有返回译文，按完整原文分析，不能声称翻译全部成功。

另一次类目确认页识别成功但勾选超时、提交次数为0，实时诊断显示点击停在可见/启用/位置稳定检查。增加目标页唤醒后，真实确认页约8.7秒、两次提交后离开，但跳到首页；原目标校验正确拒绝从首页取类目数据，显式恢复原任务后该类目成功。集合页发现Amazon把竖线分隔符再次编码，目标匹配仅对`p_78:`集合参数的该分隔符归一，仍逐项核对ASIN顺序及数量。修复后29项确认页及访问状态测试通过，含隔离Chrome场景。真实确认成功不代表所有页面都能恢复原目标；导出中途恢复在真实平台仍未单独验证，确认跳转也可能终止插件原导出。

本批最终取得29/30类目图，RV Exterior Parts & Accessories节点21571968011在定点补试后仍显示插件暂无数据，保留未知月销量及真实数量占比，完整类目门禁未通过。其它已完成模块及12指标、九图、7主图、56评论逐项校验；集合源229条、前台/插件221条、报告153个样本，三图已按本批新报告保存。原Excel指纹不变，成品和业务证据均在仓库外；确认页及网页采集阶段未做桌面端验收；后续最终283张图片嵌入版已做WPS只读打开及三类区域PDF导出核验，见[嵌入说明](final_image_embedding.md)。

用户随后确认“点击继续后有时跳到别页，需要重新进入”，已将前次人工编排的显式重进补到共享访问入口，适用于同步及异步业务。隔离Chrome验证商品、关键词、集合和类目从确认页跳到首页后能自动回原目标；另验证评论导出中途恢复时只点击一次导出。所有请求在本地拦截，未为此改动重新跑真实Excel或真实评论下载，不能保证Amazon后续永不再超时或改变页面。

隔离Chrome专项测试需设置`AMAZON_CHECKPOINT_BROWSER_TESTS=1`，再运行`python -m unittest shared.test_amazon_checkpoint.BrowserTests`；普通测试默认跳过该类。Python导入路径按项目现有测试环境设置。
