# 卖家精灵评论下载数据源（可选新版）

用户于 2026-11-24 确认：先通过浏览器探索，再沉淀本地脚本；在商品页卖家精灵插件中先勾选“翻译标题和内容”，再点击“评论下载”。下载的 Excel 是新版评价分析的数据源。本次只完成获取数据源，后续评论处理规则由用户继续说明。

原 Amazon 逐批评论抓取入口仍然保留，总调度和评价回填尚未切换。新入口为 `modules/review_research/download_sellersprite_reviews.py`。

## 前置条件

- 启动项目专用 Chrome，调试端口默认为 `127.0.0.1:9223`；沿用已登录的配置目录。
- 卖家精灵插件已启用并登录，Amazon 美国站商品页和翻译服务可以访问。当前插件提示默认 Google 翻译需要代理。
- 本地 Python 具备现有项目的 `playwright` 和 `openpyxl` 依赖。
- 运行脚本不需要 ChatGPT 浏览器扩展。卖家精灵插件是下载功能的提供方，仍然需要。

## 使用方法

在 `ecommerce-workflow-skill` 目录执行（`python` 替换为当前电脑实际解释器）：

```powershell
python modules/review_research/download_sellersprite_reviews.py B0DT8TCBNG --output-dir outputs/review-sources
```

可在同一命令传多个 ASIN 或美国站商品 HTTPS 链接。输入去重后按顺序处理。每次创建独立运行目录，不覆盖之前的文件；普通商品失败会记录原因并继续下一个商品。只有明确输入的商品会被下载，不会扫描整个数据源。

对已有下载文件进行只读校验，无需联网或连接浏览器：

```powershell
python modules/review_research/download_sellersprite_reviews.py B0DT8TCBNG --import-file "已下载评论.xlsx" --output-dir outputs/review-sources
```

可选参数：`--cdp http://127.0.0.1:9223`；`--download-timeout 180` 控制点击后等待下载事件的秒数。

## 实际流程与输出

1. 使用本地 Playwright/CDP 连接现有浏览器，只新建脚本自己的商品页。
2. 核对页面和卖家精灵面板 ASIN，再悬停“评论下载”，点击提示层中可见的“翻译标题和内容”标签；读取复选框状态确认已选中，已勾选时不会反向取消。
3. 将下载方式设为 Chrome 按原文件名保存，监听当前商品页的下载开始/完成事件，再点击一次“评论下载”。文件直接落入商品输出目录，不通过 Playwright 随机编号临时文件转存。页面的 100% 不是完成依据，须收到浏览器完成事件且文件实际存在并通过校验。
4. 保留插件原始 Excel，不用 openpyxl 重写它。只读生成 `reviews.json`，保留所有原字段、源行号、评论 ID、原文、翻译、星级、VP/Vine 标记、原文件路径和 SHA-256。
5. 完成或异常退出下载时恢复 Chrome 默认下载方式，避免以后手动下载仍落入项目目录。每商品完成后更新 `manifest.json`；只关闭脚本创建的普通商品页，不关闭浏览器或用户原有页面。

正常的 Excel 下载仍会出现在浏览器下载记录中。以前由旧脚本产生的随机编号条目是已有记录，不会随升级自动删除。若同时运行其它会设置下载方式的自动化脚本，可能互相影响，应按顺序运行。

翻译选项会在插件中保持勾选，这是用户要求的设置。脚本不自动切换翻译渠道，也不补写翻译。校验发现翻译列缺失或有原文却没有译文时，标为 `incomplete_translation`，保留文件并返回非零状态。

`downloaded` 表示该次导出已落盘且格式、数量和翻译完整；`imported` 表示本地文件通过同样校验；`empty_export` 不代表商品确实没有评论；`failed` 记录具体原因。这些状态不等于抓到了 Amazon 所有评论，也不等于评价分析完成。

## ASIN、空值和评价口径

- 用户已确认原表 ASIN 列允许为空。保持为空，不删除该评论、不报错、不擅自补成子体 ASIN。
- JSON 的 `asin` 是本次下载目标；`source_row_asin` 是导出行的原始 ASIN，可以为 null。两者不能混为一谈。`blank_source_asin_count` 只用于核对。
- 原文为空时也保留原记录并提示待核对，不编造正文。实际翻译的质量仍由后续分析阶段判断，非空校验不是翻译准确性保证。
- 下载层完整保留导出的星级、VP/Vine 记录和变体信息，并解析赞同数。筛选和分析交给独立的[新版评价分析](sellersprite_review_analysis.md)：VP或Vine，赞同数降序，好评4–5星前30条、差评1–3星前100条。
- 评分数与文字评论条数口径不同，不能用商品页评分数要求导出同等条数的文字评论。

## 验证和异常续跑

Amazon 出现登录、验证码或 `/checkpoint/continue` 时，脚本置前页面并等待最多 5 分钟。不会主动勾选真人验证框；检测到框已被勾选且“Continue shopping”可用时自动点击继续，然后从当前商品续跑。当前对话中一次现场授权操作不扩展为未来任意验证码的自动处理。

等待超时会保留验证页，当前商品标为 `needs_user_action`，剩余商品标为 `not_attempted`，停止新增请求。完成验证后只传入未完成的 ASIN 重试，不重跑已成功商品。

其它失败保留已有原文件、错误信息和截图。失败截图、JSON、Excel 放在本地输出目录，不能提交到公开仓库。
