# 最终图片嵌入与固定单元格布局

2026-11-27按用户最新要求：中间阶段仍用浮动图定位，所有采集、增行、填数、评价合并及报告三图写入结束后，由AI自动将全部浮动图片嵌入单元格。最终交付单元格图片版，不调整任何行高、列宽或合并区域。

## 执行

沿用现有转换命令，当前最终嵌入无需传`--original`：

```powershell
python scripts/make_wps_embedded_version.py --floating-workbook "最终浮动检查点.xlsx" --output "最终单元格图片版.xlsx" --manifest "本批缓存/embedded-images.json"
```

输入和输出必须不同，输出不得覆盖已有文件。默认处理全部工作表的浮动图片，包括市场调研首图、趋势图、类目图、九张市场图、竞品主图及商品数据源图片；没有图片的工作表原样保留。图片数量按本批实际读取，不写死。

## 保存与核验

- 使用ZIP/XML定点转换，沿用原文档的WPS `DISPIMG`单元格图片格式，复用原媒体文件和字节，不重采样或重编码图片。
- 图片按浮动锚点归到对应单元格；位于合并区域内时使用左上格。多个图片落在同一格、目标格已有文字/数字/公式，或者无法定位的绝对/分组图片会停止，避免覆盖内容。
- 只写图片单元格公式、移除相应浮动图片并登记图片部件；保留行列尺寸、合并、样式、富文本及非图片单元格内容。图片在固定大小的单元格内显示，不能为了容纳图片扩行扩列。
- 核对嵌入数量等于转换前浮动图片数量、最终浮动图片为0、每个编号和媒体有效、原图指纹保持；逐项对照原行高、列宽、合并、非图片内容和样式。
- 原生图表和其它非图片对象不转换；已有单元格图片保留。重复执行没有新浮动图时不重复创建图片编号。
- 先验收浮动检查点，再生成并核验嵌入版。其它业务缺失仍按实际记录，图片嵌入成功不代表缺失类目或评论已补齐。
- 嵌入完成后不能再用openpyxl整体保存成品。后续局部修正使用ZIP入口；需要重跑填表时从对应浮动检查点恢复，再做最终嵌入。

WPS已验证此图片格式；Codex内置表格预览不支持`DISPIMG`，可能显示`#NAME?`，应在WPS内检查实际图片。不能把内置预览的函数支持限制当成图片资源丢失，也不能只凭XML存在就宣称桌面显示正常。
