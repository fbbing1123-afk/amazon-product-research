# 先打开竞品页，评论导出期间取数、截图和填表

当前使用 `scripts/run_review_prefetch.py`。2026-11-26起默认同时最多2个商品开页、取数及导出，完成一个再补下一个，减少短时间集中访问。下载等待期间仍完成截图和本地填数，不改变本批全部竞品的分析范围。

## 执行入口

```powershell
python scripts/run_review_prefetch.py --workbook "已有布局检查点.xlsx" --output-dir "本地输出目录"
```

- 输入必须已有竞品ASIN、商品数据源、整体指标标签和类目布局。本入口的类目图片写入采用ZIP替换，因此需要已有类目浮动图片锚点；空模板先完成布局/图片初始化，不能直接当作完整一键入口使用。
- 默认取竞品页全部ASIN，但不会预先全部开页。`--asins ASIN1 ASIN2` 可做小范围试跑或只补失败商品；不使用整个数据源的所有ASIN。
- `--max-downloads` 默认2，同时限制商品开页和导出，槽位在文件保存/校验完成后释放。可显式调整为其它正数；它不限制本批商品总数。前台操作仍顺序执行，评论等待在后台进行。
- 首个导出启动后即可计算本地整体指标，首批商品完成取证后开始类目截图；竞品数值及主图统一等本批取证结束后顺序写入，确保后续批次也被完整填入。
- 单一Playwright连接、整批固定下载目录。按页面frame和下载GUID对应ASIN，再核验文件名、工作表、评论数量及源指纹。不更名或搬走下载文件，保留Chrome下载记录的正常Excel文件名。
- 每页先勾选“翻译标题和内容”，只点一次下载；卖家精灵显示100%不代表文件已生成，必须等浏览器完成事件并读取文件校验。
- 每个商品总等待默认600秒，可通过 `--download-timeout` 修改；连续180秒无新进度则记录停滞，保留页面与已成功结果，不默默重复点击。
- 原生输入不覆盖，各阶段只写独立检查点。先写整体指标，再写竞品基础数值和网页高清主图，最后合并类目图片，禁止多个任务同时保存同一个工作簿。

## 同页数据与后续分析

`modules/competitor_analysis/prefetch_basics.py` 复用导出页，数据源优先，缺项才读取插件月销量、价格、上架时间及Amazon About this item。Alexa推荐问题作为维度参考保存，不能视为产品支持功能的证据。

当前阶段自动写入月销量、价格、上架时间。2026-11-25新增同页采集[高清产品主图](product_images.md)，核验后顺序写入 `01-product-images.xlsx`，后续类目截图合并沿用此检查点。默认 `--product-image-display original`，原尺寸浮动，不改行高列宽。主图与数值分别记录失败，基础字段失败不丢失已取主图，缺图不能报告预取阶段完成。

原始卖点、推荐问题和 `main_image` 证据保存在 `basic-facts.json`，供既有主智能体中文卖点/最多5项对比流程使用，不把英文原文覆盖到已整理的中文单元格。后续基础填表传递同批主图证据，避免换回数据源小图。评分、中文卖点、对比和评价仍按新版既有基础/语义入口完成，不能把此阶段的证据齐全状态当作完整竞品分析完成。

每商品下载输出原始Excel和 `ASIN/reviews.json`。下一阶段直接使用这些文件筛样和生成本批分析，不再次下载、不沿用其它源指纹的旧分析。最终仍通过 `fill_review_batch.py` 将全部原评论和3列分析合并回唯一 `评价数据源`，最左列为分析商品ASIN。

## 页面与失败处理

- 启动商品页后保留到文件保存且归属/内容校验成功才关闭。失败、超时或真人验证页保留，不能为了清理标签页提前关掉仍在导出的商品。
- 截图成功后关闭本入口新开的类目页；用户原有页不擅自关闭。历史无用任务页在用户要求时另行清理。
- 如退出时仍有未完成导出，下载目录暂时保留到本批目录，防止后续文件掉到别处；清单中记录 `downloads_pending`。此时不要直接并行启动其它浏览器脚本，先处理/刷新停滞页并恢复该商品，最后恢复默认下载设置。
- Amazon已知确认页按[共享处理规则](amazon_checkpoint.md)在原UI操作锁内勾选并提交，恢复后核验ASIN、邮编和插件；只等待原导出，不重复点击下载。期间不补开新商品或类目，已有下载继续接收事件。其它验证或处理失败保留页面，暂停新访问并按清单定点继续，本地计算仍可进行。
- 未完成导出若发生错误或停滞，停止补开后续商品，避免遗留下载与新任务叠加。`manifest.json` 的 `access_paused` 记录访问暂停，`remaining_asins` 列出未完成商品；恢复前先核验仍在下载的文件，已落盘时用 `save_export` 补记录，不能直接重复点击导出。
- 已完成的截图/数值无需重跑。基于最新检查点使用 `--skip-categories`、`--skip-metrics` 和失败ASIN集合；未成功的图片可用 `--category-start`、`--category-limit` 单独补齐。已生成Excel但记录保存失败时，调用 `save_export` 核验并补记录，不重新下载。
- `manifest.json`、`events.jsonl` 保存真实时间、结果与错误。`overlap_evidence` 仅统计实际完成的下载时段内出现的填数/实际截图事件，不把启动截图的20秒等待当作已截图，也不估算没有对照测量的提速百分比。
