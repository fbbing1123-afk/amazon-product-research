# 从商品数据源直接生成Amazon集合链接

2026-11-25按用户要求替换卖家精灵“链接生成器”步骤：先在网页逐站实际生成示例，核对格式，再在本地读取商品数据源ASIN生成链接。正常运行无需打开链接生成器，也不需要为生成链接登录卖家精灵。

## 实测格式与站点

在卖家精灵“集合链接”页使用同一组3个ASIN，逐个选择以下12个站点并点击“生成链接”。可见输出与“打开”按钮的目标均为：

```text
https://www.站点域名/s?rh=p_78:ASIN1|ASIN2|ASIN3
```

| 站点 | 代码 | 域名 |
| --- | --- | --- |
| 美国 | US | amazon.com |
| 日本 | JP | amazon.co.jp |
| 英国 | UK | amazon.co.uk |
| 德国 | DE | amazon.de |
| 法国 | FR | amazon.fr |
| 意大利 | IT | amazon.it |
| 西班牙 | ES | amazon.es |
| 加拿大 | CA | amazon.ca |
| 印度 | IN | amazon.in |
| 墨西哥 | MX | amazon.com.mx |
| 巴西 | BR | amazon.com.br |
| 澳洲 | AU | amazon.com.au |

12站只有域名不同，路径、`rh=p_78:`和竖线分隔方式一致。保存时去除网页结果末尾多余空白，使用原始冒号和竖线，不重复百分号编码。映射及实测日期在 `resources/asin_collection_sites.json`。来源：[卖家精灵链接生成器](https://www.sellersprite.com/v3/link-builder)。

## 执行入口

```powershell
python scripts/build_amazon_collection_link.py --workbook "当前报告.xlsx" --output-dir "本地输出目录"
```

用户明确站点时通过 `--site JP` 等参数传入；未指定时先根据商品源详情链接（含Excel超链接目标）识别站点，源链接缺失时从竞品详情链接识别，都没有信息才默认US。也接受“日本站”等中文名称，`GB`归一为`UK`。指定站点与原商品链接冲突、源链接混用站点时停止，不能默默使用美国站。

默认选择唯一的商品数据源页，识别时忽略页名首尾空白，不要求与市场调研或竞品页使用相同前缀，排除评价/评论数据源。多商品源时用 `--sheet "实际页名"` 指定。必须有唯一的 `ASIN` 列，不能改取父ASIN、竞品列表或评论ASIN。逐行读取全部源商品，不按月销量、子体销量、父ASIN、隐藏行或Excel筛选状态删除记录。去除空白、转大写并按原顺序去重；非空错误ASIN报告源单元格，不静默丢弃。

不设置200条上限，不截断、不自动分批。每次生成独立输出目录，含可复制的 `collection-link.txt` 和记录源文件指纹、页名、站点、ASIN顺序及源行号的 `collection-link.json`。原工作簿只读，不覆盖或另存Excel。

## 接入工作流

新版市场报告阶段先运行本入口，打开生成的Amazon集合链接，再用卖家精灵插件加载商品、进入市场分析并生成报告，后续三图截图和填表保持既有流程。链接生成不再依赖卖家精灵网页UI。`preflight_browser.py` 登录态检查改用卖家精灵首页，不再跳转链接生成器；该检查服务于其它卖家精灵功能，单独生成链接无需运行浏览器前检。

本模块支持上述12站的链接生成，不代表其它采集模块已经支持12站；原有站点能力保持各模块自己的范围。加载更多和生成报告仍由主智能体编排，不能称为完整一键市场报告流程。

## 验证记录与边界

- 本地生成结果与网页逐站实测的12条示例链接逐条一致。
- 真实商品源229个有效ASIN全部进入同一美国站链接，0重复、未截断，源文件SHA256保持。
- 11项相关测试通过，覆盖200条以上保序、错误ASIN、销量空白/零值不筛除、父ASIN/评论源排除、Excel超链接识别、站点冲突、多源歧义，以及浏览器前检不再跳转链接生成器。
- 此次验证的是生成规则和源数据完整性，未对12个Amazon站点分别验证商品结果数。生成链接所含数量、Amazon实际返回数量、插件加载数量和最终市场报告样本数量仍需分别记录。
- 源码、站点规则、测试及文档由Git跟踪；真实源表、生成链接和浏览器观察记录仅本地保存，未推送。
