# 同事测试包分发

当前包只提供最新流程与填写指引，模板为用户确认的 `assets/产品调研模板.xlsx`。模板数据源为空，市场调研A3和竞品分析A1保留示例ASIN，用户使用时替换。原始模板按字节复制，不重存Excel。

维护者在仓库根目录先提交本次已核对改动，再运行：

```powershell
python tools/build_test_package.py --version 20261125-test1 --output-dir 本地分发目录
```

入口需要Git，只用于维护者打包；同事解压使用不需要Git。只读取已提交源码，不删除或搬动开发机的依赖、缓存、浏览器状态。输出独立ZIP、SHA256文件及包内 `PACKAGE-MANIFEST.json`，记录源提交和所有文件指纹。

包内含最新Skill、使用指南、填写说明、模板、阶段规则、运行脚本和必要资源。旧DOCX指南、旧竞品角色、历史独立市场分析说明、旧评价翻译和语义缓存均排除；开发历史日志也不放进同事包。必要共用底层代码保留，实际执行入口只由当前SKILL和阶段规则指定。

除明确授权的空数据源模板外，不带业务Excel、截图、下载、运行日志、凭据、Cookie、浏览器配置、`.venv` 或 `node_modules`。仅该模板获得精确Git忽略例外，不整体放开Excel保护。`.gitignore`仅影响未跟踪的新文件，已跟踪文件仍可修改、提交和回退。

分发前检查：包内关键文件、文档引用、模板解析和SHA256一致；解压到独立目录验证环境复用不会安装，缺依赖时才在项目内准备；检查主要CLI和离线图表。安装检查不替代同事电脑的插件登录及业务实跑，验证记录必须写清实际范围。

同事先看包根 `开始使用.txt`，再用使用指南里的指令让AI检查环境。已有环境可通过 `-Python`、`-NodeModules` 复用；当前包本机记录在 `.workflow-state/runtime.json`，不会随下一次分发带出。
