# 卖家精灵三张截图：动态定位入口

这是可选的三张网页图表版本。2026-11-24新增 `capture_sellersprite_report_charts.py`，可通过项目CDP从已经生成的卖家精灵市场报告截图，再交给本入口动态放图。2026-11-25集合链接已改为[读取商品数据源本地生成](asin_collection_links.md)，无需打开卖家精灵链接生成器；点击加载更多及生成报告仍需主智能体编排，尚未接入一键总调度。详见 [新版全流程试跑](new_workflow_trial.md)。

## 放置规则

- 在指定的市场调研页中，分别唯一匹配 `Review数量分析`、`Rating分析`、`价格分析`（忽略空白和英文大小写）。每次运行重新找标签，不固定使用第 21～23 行。
- 将截图放在标签紧邻右侧的合并区域，按当前行高、列宽等比缩放并留白。右侧结论区域保持空白；不改变现有单元格样式、行高、列宽或合并范围。
- 生成普通浮动图片（单单元格锚点），不生成 WPS `DISPIMG` 或嵌入单元格图片。
- 标签缺失、重复或右侧没有合并区域时明确报错，不猜位置。
- 重复运行只替换本入口生成的三张图，保留其它图片。输入、输出必须不同，保护原文件。
- 通过 ZIP/XML 定点写入绘图部件，不使用 openpyxl 整体保存；保留 WPS 原生图片及其它工作表部件。

## 调用示例

在 `ecommerce-workflow-skill` 目录执行：

```powershell
python modules/product_research/scripts/insert_sellersprite_screenshots.py --input "已完成关键词和类目的报告.xlsx" --output "三图报告.xlsx" --review "review-count-chart.jpg" --rating "rating-chart.jpg" --price "price-chart.jpg"
```

如有多个市场调研页，用 `--sheet "具体页名"` 指定。本入口不检查三张截图是否属于工作簿里的产品，调用方必须保证数据来源一致。

## 增行规则与使用顺序

关键词回填与类目填充共用 `modules/shared/worksheet_rows.py`。新增行复制所属模块的模板行样式；下方模块的原样式、行高、行分组/隐藏属性、合并区域一起下移。已加载的浮动图片和图表支持字符串、单单元格、双单元格锚点；双单元格锚点的起点、终点同时移动。

推荐顺序是先完成关键词与类目扩容，再调用本截图入口。共享增行函数负责内存中的布局，不能替代原有工作流的 WPS 图片保护或切片器保存规则；创建切片器后仍不得用 openpyxl 整体保存文件。
